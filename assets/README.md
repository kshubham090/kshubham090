## Profile banner

`profile-banner-source.svg` is the editable design. It uses Raleway for the name and Outfit for supporting text. `profile-banner-v3.svg` converts that text to vector outlines so GitHub displays the intended fonts without external font requests. The main README references the versioned export to avoid reusing a cached image URL.

Font sources (SIL Open Font License): [Raleway](https://github.com/google/fonts/tree/main/ofl/raleway), [Outfit](https://github.com/google/fonts/tree/main/ofl/outfit).
